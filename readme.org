#+title: mixénergie
#+subtitle: Mix énergétique du Québec, de l'Ontario et de l'Alberta

Site simple, pour lire le mix électrique d'Hydro-Québec, de l'IESO et de l'AESO : production, demande, échanges et mix annuel.

* Stack

| Concern     | Choix                                      |
|-------------+--------------------------------------------|
| Front       | Vite + React + TypeScript                  |
| Style       | Tailwind CSS v4                            |
| API         | Worker + KV (snapshot 15 min, annuel 24 h) |
| Hébergement | Cloudflare Workers + static assets         |

* Données

Sources officielles d'Hydro-Québec (CC BY-NC 4.0) :

- Production horaire :: https://www.hydroquebec.com/data/documents-donnees/donnees-ouvertes/json/production.json
- Demande 15 min :: https://www.hydroquebec.com/data/documents-donnees/donnees-ouvertes/json/demande.json
- Import / export :: https://donnees.solutions.hydroquebec.com/donnees-ouvertes/data/json/importexport.json
- Historique annuel :: https://donnees.hydroquebec.com/explore/dataset/historique-production-electricite-quebec/

Les timestamps HQ sont en heure de l'Est, sans fuseau. Le site les affiche tels quels.

Délais connus : ~90 min pour l'hydraulique / éolien / solaire / autres, ~6 h pour le thermique, 15 min pour la demande.

L'intensité GES (g/kWh) est une moyenne pondérée des facteurs de cycle de vie publiés par Hydro-Québec. Le poste "autres renouvelables" n'a pas de facteur officiel : 45 g/kWh (estimation).

** Ontario

Rapports publics de l'IESO (=reports-public.ieso.ca/public=) :

- Production par combustible :: =GenOutputCapability= (aujourd'hui) et =GenOutputCapability_AAAAMMJJ= (hier), somme par combustible des sorties horaires des centrales
- Demande :: =Demand.csv= (publié une fois par jour), complété par les archives =RealtimeTotals_AAAAMMJJHH= (gardées dans KV) et =RealtimeTotals= (5 min)
- Échanges :: =IntertieScheduleFlow=, flux réels aux 5 min, 14 zones regroupées en 5 marchés (Québec, New York, Manitoba, Michigan, Minnesota)
- Mix annuel :: =GenOutputbyFuelMonthly_2025=

L'IESO date tout en heure normale de l'Est (HNE), heure de fin d'heure. Le worker convertit en heure murale de Toronto, comme Hydro-Québec. Les installations intégrées aux réseaux de distribution ne sont pas dans ces rapports.

L'intensité GES utilise les médianes de cycle de vie du GIEC (AR5) : nucléaire 12, hydraulique 24, éolien 11, solaire 48, biomasse 230, gaz 490 g/kWh. Les sorties « autres » de l'IESO sont exclues de la moyenne. Le chiffre principal est la part sans émissions (nucléaire inclus) ; la part renouvelable est affichée en dessous.

** Alberta

Rapport « Current Supply Demand » de l'AESO, en CSV (=ets.aeso.ca/ets_web/ip/Market/Reports/CSDReportServlet?contentType=csv=), sans clé d'API, mis à jour environ chaque minute :

- Production :: production nette (TNG) par groupe : cogénération, cycle combiné, vapeur au gaz, cycle simple, éolien, hydraulique, solaire, stockage, autres
- Demande :: charge interne de l'Alberta (AIL)
- Échanges :: flux net sur 3 interconnexions (Colombie-Britannique, Saskatchewan, Montana), positif = exportation

Le rapport n'a pas d'historique ni de mix annuel. Le worker ajoute un relevé aux ~10 minutes dans KV (=mix:ab:history=, 48 h), donc le graphique se remplit depuis la mise en service. Les heures sont en heure des Rocheuses (=America/Edmonton=). Intensité GES : médianes GIEC (hydraulique 24, éolien 11, solaire 48, filières au gaz 490 g/kWh) ; stockage et « autres » exclus.

* Cache

| Couche            | Quoi             | Durée                                  |
|-------------------+------------------+----------------------------------------|
| KV =mix:snapshot= (=mix:on:snapshot= pour l'Ontario) | Payload assemblé | Frais tant que la demande a moins de ~16,5 min, servi périmé jusqu'à 6 h |
| KV =mix:year=     | Mix annuel 2025  | Frais 24 h, TTL 7 jours                                                  |
| Lecture KV        | =cacheTtl= 60 s  | Cache de bord des lectures (minimum KV)                                  |
| Navigateur        | =Cache-Control=  | Frais 1 min + SWR 1 min ; périmé max-age 0                               |
| Cron              | =*/5 * * * *=    | Réchauffe les snapshots de chaque province                               |

Les requêtes lisent KV. Un snapshot encore frais (demande du quart d'heure en cours) est renvoyé tel quel. Un snapshot d'un intervalle en retard est renvoyé tout de suite, puis rafraîchi en arrière-plan. Deux intervalles ou plus de retard : rafraîchissement synchrone. Le mix annuel n'est refetché qu'une fois par jour.

Le namespace KV =MIX= est auto-provisionné (local au =dev=, créé au =deploy=).
